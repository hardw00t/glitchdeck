# v2.2.0 release notes

- Decode gzip, x-gzip, and deflate before applying matching SSE faults. Unmatched and unsupported encodings pass through unchanged.
- Assert provider and custom SSE terminal events independently of the transport close. Inject provider errors or corrupt streamed tool arguments without breaking the outer JSON.
- Simulate a bounded retry storm with provider rate-limit envelopes and headers.

## Loopback SDK smoke tests

Python OpenAI 3.60.0 and Anthropic 2.14.0 ran through `glitchdeck exec` against a local fixture, without provider network calls.

| Scenario | Observed result |
| --- | --- |
| OpenAI starter, cut after three events | Returned `tok0 tok1 tok2`, `finish_reason: null`, no exception. |
| Anthropic starter, cut after three events | Returned `tok0`, `stop_reason: null`, no exception. |
| OpenAI midstream error | Raised `APIError: Overloaded` after three text chunks. |
| Anthropic midstream overload | Raised `APIStatusError`. |
| OpenAI retry storm | Retried twice and returned HTTP 200. Observed request gaps: 204 ms and 202 ms. |
| OpenAI tool arguments, truncate | The stream finished with `finish_reason: tool_calls`; `json.loads(arguments)` raised `JSONDecodeError`. |

All six runs met their tape expectations. Assert the finish reason or stop reason when a short answer must not count as success.
